# SQL_Learning_Lab_DML_04

Aplicación para practicar y aprender comandos DDL y DML de SQL.

## Funcionalidad

- Editor SQL con botones para ejecutar, borrar, inicializar, eliminar y actualizar la base de datos.
- La cabecera cambia de color aleatoriamente cuando un comando SQL se ejecuta correctamente.
- Si ocurre un error al ejecutar un comando, la cabecera se vuelve roja para indicar fallo.
- Área de resultados que muestra las consultas SELECT en formato de tabla.
- Visualización gráfica de las tablas creadas y sus estructuras en el panel derecho.
- Usa `sql.js` desde CDN para ejecutar SQLite en el navegador.

## Uso

1. Abre `index.html` en un navegador moderno.
2. Escribe una consulta SQL en el editor.
3. Pulsa `Ejecutar` para ver los resultados en la tabla inferior.
4. Observa las tablas creadas en el panel derecho.
