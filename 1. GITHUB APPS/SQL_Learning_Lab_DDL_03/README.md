# SQL_Learning_Lab_DDL_03

Aplicación combinada para practicar DDL con ejemplos rápidos de SQL.

## Funcionalidad

- Editor de SQL con controles para ejecutar código y ver la estructura actual de tablas.
- Visualiza las tablas creadas y sus columnas en tarjetas de colores.
- Incluye botones de ejemplo para cargar SQL de `Crear tabla`, `Insertar datos`, `Consultar datos`, `Actualizar datos` y `Unir tablas`.
- Añade un botón para `Reiniciar BD`, que borra toda la estructura existente y deja la base de datos vacía.
- Permite usar TAB para sangrar dentro del editor y Ctrl+Enter para ejecutar.
- Usa `sql.js` desde CDN para ejecutar SQLite en el navegador.

## Uso

1. Abre `index.html` en un navegador moderno.
2. Usa los botones de ejemplo para cargar SQL en el editor.
3. Pulsa `Ejecutar` o `Ctrl+Enter` para ejecutar el SQL.
4. Mira las tablas creadas a la izquierda y el estado en el área de salida.
